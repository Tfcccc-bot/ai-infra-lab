1先把「认可度」拆成可以核验的信号

团队的认可度不是一个官方字段，而是横向决策指标。本页将「贡献了什么」和「别人是否在用」分开记录：Star 是关注度，下载/开发者/适配是采用度，论文与系统落地是技术产出，薪资另行估计。

30%

可复用开源影响力

旗舰仓库 Star、Fork、贡献者和持续更新。示例：vLLM、PaddleOCR、Colossal-AI、MiniCPM、verl。Star 只代表关注度，不等于生产采用。

20%

生态采用规模

官方下载量、开发者、模型/应用衍生、伙伴和硬件适配。示例：昇腾 400万+开发者、MindSpore 1550万+下载、Qwen 生态。

20%

系统与学术产出

顶会论文、训练/推理系统、通信/并行/编译器/内核、可复现实验。示例：PagedAttention、DeepEP、Mooncake、Open-Sora。

15%

模型或算力落地

模型能力、生产流量、国产芯片训练/推理、客户部署、端侧效率等。厂商自报数据必须标注，不能当成独立第三方评测。

15%

组织与社区信号

OpenRank、活跃贡献、标准/基金会、开发者活动、跨公司协作和生态伙伴。组织规模大的公司会天然占优，需和单点创新分开看。

评分公式：综合分 = 30%×开源 + 20%×生态 + 20%×系统/学术 + 15%×模型/算力落地 + 15%×组织社区。每项按公开信号归一化到 0–100，再四舍五入。它适合做候选团队排序，不是招聘评级，也不等于个人成长速度。
工作内容怎么读

训练：并行策略、数据、优化器、RL/后训练；推理：KV Cache、调度、量化、Kernel、PD 分离；芯片：编译器、算子、通信、框架适配；平台：MLOps、资源调度、可观测性和成本。

产出怎么读

优先看「代码 + 论文 + 可复现实验 + 被其他框架/硬件接入」。单独发布模型权重，不能自动证明团队有强 Infra 能力。

薪资怎么读

校招使用月薪×薪数+签字费+首年归属股票；社招使用现金年薪/总包区间。股票、期权和一次性奖励必须和现金分开。

3秋招 / 社招薪资估计器

估计器把岗位方向系数、公司梯队、学历、Offer 档位和背景放在一起。社招档采用公开行业区间校准，不代表任何单家公司正式报价。

校招口径：月薪基数×月数 + 签字费 + 首年归属股票。社招口径：以基准现金年薪×方向/学历/背景系数，再加总包溢价；股权兑现风险不纳入现金。

4薪资基准：校招公开开奖 + 社招方向行情

5数据来源、链接与边界

硬指标与技术产出

  • MindSpore 官方站：1550万+下载、38.3K+ Star、92.8K+ Issue、133K+ PR（官网快照）。
  • PaddleOCR GitHub：约 86K–88K Star；科学网报道记录其超过 Tesseract 并支持 100+语言。
  • vLLM GitHub：约 89K Star、20K+ Fork、2K+贡献者（公开页面/行业快照）；PagedAttention 论文发表于 SOSP 2023。
  • Colossal-AI GitHub：约 41K Star；Open-Sora约 29K Star，2.0 训练代码与权重开源。
  • MiniCPM GitHub：约 10K Star；MiniCPM-V/o 另有多模态仓库，重点产出是端侧效率、稀疏注意力和全双工多模态。
  • Hugging Face 中国开源生态观察：记录 DeepSeek、Qwen、Mooncake、国产芯片 day-zero 适配等系统性趋势。

组织规模与算力生态

  • 中国工信新闻网转引昇腾进展：2025年底昇腾开发者超 400万、伙伴超3000家、解决方案超6700个；CANN 30+社区项目、1500+开发者。
  • MindSpore 官方：覆盖 130+国家/地区，提供 MindSpore Transformers、MindSpore Lite、vLLM-MindSpore Plugin 等生态组件。
  • DeepSeek：R1/DeepEP/FlashMLA/DeepGEMM/DualPipe/3FS 等公开项目，指标以对应仓库实时页面为准；不能把模型 Star 直接等价为 Infra 贡献。
  • 国产芯片部分优先看软件栈、框架适配、集群互联和真实客户落地；单卡峰值算力多为厂商口径，不直接与不同精度/软件栈的 H100 做结论。

薪资来源与校准

  • 校招：牛客/OfferShow/公开开奖整理、CSDN/新东方大厂秋招汇总；页面保留典型区间而非个案最高值。
  • 社招：公开招聘/猎头行业报告交叉整理。参考区间：大模型算法约 50–200万；AI Infra（CUDA/分布式）3–5年约 60–120万；推理优化约 42–72万；分布式训练约 46.8–76.8万；AI 芯片适配约 40.8–68.4万。
  • 猎头报告页面给出分布式训练基建专家、推理优化等岗位的公开区间，但报告主体并非官方统计。
  • 网页估计器使用梯队基数，不等价于某个具体岗位的 offer letter；城市、职级、签字、期权归属和税前税后口径都会显著改变结果。

必须注意的边界

  • GitHub Star、下载量、模型调用量是不同指标，不能相加。
  • 厂商自报性能、客户数量、训练成本须视为「厂商证据」，不是独立 benchmark。
  • 公司级认可度不等于某个具体组；同一公司研究院、业务线、芯片/平台线的工作体验和薪资可以差异很大。
  • 所有数字仅用于求职前的横向研究，不能作为招聘、投资或薪酬决策依据。
